CHILL ZONE SMP 26.3 - CUSTOM RECIPE DATAPACK (DRAFT v1)
=======================================================
Minecraft Java 26.3 / Fabric server; datapack format 121.0.

INSTALL
1. Back up the server world.
2. Put CHILL_ZONE_RECIPES_26.3_V1.zip inside the active world's datapacks folder, unchanged.
3. Run 'reload' in console (or restart).
4. Run 'datapack list enabled' to confirm enabled.
5. Test each recipe in a creative/test world before live use.

RECIPES
FINAL EXACT AS REQUESTED
- Cobweb: string in the 4 corners and middle of crafting grid = 1 cobweb.
- Golden apple: apple center, gold ingots cardinal four sides = 1 golden apple. Replaces vanilla golden apple recipe.

PROVISIONAL / ADJUSTABLE INGREDIENT COUNTS
- Gunpowder: charcoal center + 4 flint cardinal = 2 gunpowder.
- Wool to string: any 1 wool = 4 string.
- No-bow dispenser: 1 dropper center plus 1 string above & below = 1 dispenser.
- Rotten flesh to leather: smelt 1 rotten flesh in a furnace = 1 leather.
- Sponge: 8 yellow wool surrounding 1 slime block = 1 sponge.
- Bell: 4 gold ingots cardinal + 1 iron ingot center = 1 bell.
- Horse armor: 6 iron ingots / gold ingots / diamonds arranged ['  M','MMM','M M'] = corresponding horse armor.
- Sand: blast 1 gravel = 1 sand; cookingtime explicitly 200 ticks per 26.3 format.
- Crying obsidian: 1 obsidian center + 4 amethyst shards cardinal = 1 crying obsidian.
- Chainmail recipe NOT included. No Totem/Elytra/Netherite recipes.

NOTE: This ZIP is syntactically validated JSON, not run inside Minecraft.
Bedrock players via Geyser may need a crafting table test (recipe book sync varies).
This package is a Java datapack, not a jar mod.
